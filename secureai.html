SecureAI Web Harness

A coding-agent harness for database-driven web applications. The project focuses on automated implementation, verification, evaluation and security.

Project Overview

The goal of this project is to build a harness that supports an AI coding agent in developing and verifying database-driven web applications.

Project Focus

AI Coding Agent

The coding agent implements software changes based on specifications and project context.

Verification Loop

Automated tests and checks provide feedback to the agent, allowing it to detect and fix errors.

Evaluation

The harness is evaluated using predefined tasks, success rates, runtime and resource usage.

Security

The project includes permission rules, sandboxing and tests against prompt injection attacks.
